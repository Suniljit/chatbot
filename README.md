# Chatbot
This is a simple Chatbot implementation using the OpenAI API as well as Streamlit. 

To run the Chatbot, you will need to follow the following instructions:
1. Install the packages in the requirements.txt file
2. Create a .streamlit folder and create a secrets.toml file to store your OpenAI API key. 
3. The API key should follow this format: 
```OPENAI_API_KEY = "your-api-key"```
4. Run the streamlit app using the command: 
```streamlit run chatbot.py```
